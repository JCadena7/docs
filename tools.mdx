Estas son las herramientas que usamos en nuestros proyectos de investigación.
Están organizadas por categoría para facilitar su consulta.

<Tabs>
  <Tab title="Lenguajes">
    <Columns cols={2}>
      <Card title="Python" icon="code" href="https://python.org">
        Lenguaje principal para análisis de datos, machine learning y automatización.
        Lo usamos con bibliotecas como Pandas, NumPy, scikit-learn y Matplotlib.
      </Card>
      <Card title="R" icon="code" href="https://r-project.org">
        Usado para análisis estadístico avanzado y modelado econométrico.
        Bibliotecas principales: tidyverse, ggplot2, caret.
      </Card>
      <Card title="SQL" icon="database">
        Lenguaje estándar para consulta y manipulación de bases de datos
        relacionales. Usado con PostgreSQL y MySQL.
      </Card>
      <Card title="Scala" icon="code" href="https://scala-lang.org">
        Lenguaje funcional usado con Apache Spark para procesamiento
        distribuido de alto rendimiento.
      </Card>
    </Columns>
  </Tab>
  <Tab title="Plataformas">
    <Columns cols={2}>
      <Card title="Apache Spark" icon="bolt" href="https://spark.apache.org">
        Framework de procesamiento distribuido para datos a gran escala.
        Lo usamos via PySpark para pipelines de datos.
      </Card>
      <Card title="Apache Kafka" icon="arrows-split-up-and-left" href="https://kafka.apache.org">
        Plataforma de streaming de eventos para procesamiento en tiempo real.
      </Card>
      <Card title="Jupyter Notebooks" icon="notebook" href="https://jupyter.org">
        Entorno interactivo para experimentación, prototipado y documentación
        de análisis de datos.
      </Card>
      <Card title="Google Colab" icon="cloud" href="https://colab.research.google.com">
        Notebooks en la nube con acceso a GPU. Ideal para compartir
        experimentos y colaboración remota.
      </Card>
    </Columns>
  </Tab>
  <Tab title="Visualización">
    <Columns cols={2}>
      <Card title="Power BI" icon="chart-bar" href="https://powerbi.microsoft.com">
        Herramienta de business intelligence para dashboards interactivos
        y reportes ejecutivos.
      </Card>
      <Card title="Tableau" icon="chart-pie" href="https://tableau.com">
        Plataforma de visualización de datos para análisis exploratorio
        y presentaciones.
      </Card>
      <Card title="Streamlit" icon="display" href="https://streamlit.io">
        Framework de Python para crear aplicaciones web de datos de forma
        rápida, sin necesidad de conocimientos de frontend.
      </Card>
      <Card title="Plotly" icon="chart-line" href="https://plotly.com">
        Biblioteca de visualización interactiva disponible en Python, R
        y JavaScript. Ideal para gráficos web y dashboards.
      </Card>
    </Columns>
  </Tab>
  <Tab title="Cloud y DevOps">
    <Columns cols={2}>
      <Card title="Google Cloud Platform" icon="cloud" href="https://cloud.google.com">
        Servicios de cómputo en la nube: BigQuery, Cloud Storage, Vertex AI.
      </Card>
      <Card title="GitHub" icon="github" href="https://github.com">
        Control de versiones y colaboración. Todos nuestros proyectos
        tienen repositorio abierto en GitHub.
      </Card>
      <Card title="Docker" icon="box" href="https://docker.com">
        Contenedores para ambientes reproducibles de desarrollo
        y experimentación.
      </Card>
      <Card title="VS Code" icon="code" href="https://code.visualstudio.com">
        Editor de código principal del equipo, con extensiones para
        Python, Jupyter y Git.
      </Card>
    </Columns>
  </Tab>
