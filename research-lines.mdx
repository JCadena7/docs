El semillero GEAB organiza su trabajo investigativo en cuatro líneas temáticas.
Cada línea aborda un área específica de la ciencia de datos y cuenta con
proyectos, publicaciones y un equipo dedicado.

<AccordionGroup>
  <Accordion title="Big Data y computación distribuida" icon="database">
    Investigamos cómo procesar y analizar grandes volúmenes de datos usando
    tecnologías de computación distribuida.

    **Temas de interés:**
    - Arquitecturas de procesamiento distribuido (MapReduce, Spark)
    - Almacenamiento y consulta de datos a escala (HDFS, data lakes)
    - Optimización de pipelines de datos en entornos cloud
    - Procesamiento de datos en tiempo real (streaming)

    **Tecnologías principales:** Apache Spark, Apache Kafka, Hadoop, Python, Scala

    **Investigador líder:** Carlos Eduardo Méndez

    **Proyectos asociados:**
    - [Dashboard de indicadores urbanos](/active-projects)
  </Accordion>

  <Accordion title="Machine learning aplicado" icon="brain">
    Desarrollamos modelos de machine learning para resolver problemas concretos
    en educación, salud pública y ciencias sociales.

    **Temas de interés:**
    - Modelos de clasificación y regresión para problemas sociales
    - Procesamiento de lenguaje natural (NLP) en español
    - Aprendizaje supervisado y no supervisado
    - Validación y evaluación de modelos en contextos reales

    **Tecnologías principales:** scikit-learn, TensorFlow, PyTorch, Hugging Face, NLTK

    **Investigador líder:** Diego Alejandro Vargas

    **Proyectos asociados:**
    - [Análisis predictivo de deserción](/active-projects)
    - [Análisis de sentimientos en redes sociales](/active-projects)
  </Accordion>

  <Accordion title="Analítica de datos aplicada" icon="chart-bar">
    Aplicamos técnicas estadísticas y de analítica de datos para generar
    conocimiento accionable a partir de datos reales.

    **Temas de interés:**
    - Análisis exploratorio de datos (EDA)
    - Modelado estadístico y series temporales
    - Analítica de negocios y cadenas de suministro
    - Minería de datos y descubrimiento de patrones

    **Tecnologías principales:** Python (Pandas, NumPy, SciPy), R, SQL, Excel avanzado

    **Investigadora líder:** Dra. María Alejandra Torres

    **Proyectos asociados:**
    - [Optimización logística en cadenas de suministro](/active-projects)
  </Accordion>

  <Accordion title="Visualización de datos y comunicación científica" icon="chart-pie">
    Exploramos cómo comunicar resultados de investigación de forma clara
    y accesible a través de visualizaciones interactivas y narrativas de datos.

    **Temas de interés:**
    - Diseño de dashboards interactivos
    - Narrativa de datos (data storytelling)
    - Visualización geoespacial
    - Accesibilidad en visualizaciones

    **Tecnologías principales:** Power BI, Tableau, D3.js, Plotly, Matplotlib, Streamlit

    **Investigadora líder:** Laura Valentina Ríos

    **Proyectos asociados:**
    - [Dashboard de indicadores urbanos](/active-projects)
  </Accordion>
</AccordionGroup>
